## ✨ Features & Architecture

- **🌌 Cosmic Hero Experience**: Full-screen cosmic background with custom Spock Essential typography, call-to-action buttons, and quick contract copy pill.
- **🛡️ Feature Cards**: Glassmorphic feature grid with animated twinkling starfield and glowing purple hover effects.
- **📖 About Section**: Responsive dual-view section (Desktop 1920x1080 background / Mobile 1080x1920 background) featuring animated gradient title text (`A JOURNEY BEYOND THE STARS`).
- **📊 Tokenomics Dashboard**: Interactive card displaying token stats, interactive contract copy box, floating spacecraft artwork, and custom font metric badges.
- **🚀 5-Phase Roadmap**: Connected timeline with 6-sided hexagon badges, AVIF character artwork cards, and detailed mission milestones.
- **📝 Whitelist Section**: Feature breakdown box (`THE FIRST CIRCLE OF EXPLORERS`), perk badges, and interactive step-by-step join guide (`HOW TO JOIN`).
- **🛰️ Socials & Community Banner**: Dedicated desktop/mobile social share section with instant links to Telegram & X.
- **🧭 Custom Navbar & Footer**: Top navigation bar with section scrolling, mobile drawer menu, and character footer.
- **🚀 Optimized SEO**: Pre-configured Next.js Metadata, OpenGraph social banner, Twitter Cards, `sitemap.ts`, and `robots.ts`.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ayanmal1k/Qyona.git
   cd Qyona
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
